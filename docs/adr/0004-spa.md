# 0004. Frontend is a static SPA, not SSR

**Status:** Accepted

## Context

The UI started on TanStack Start with server-side rendering and a Cloudflare Worker build. In practice nothing benefited from SSR: the globe is WebGL and renders client-side only, traffic refreshes every minute, and the briefing and weather texts come from an LLM and take seconds, too slow to block a server render.

## Decision

Build a plain Vite SPA with TanStack Router (file-based routes, typed search params) that builds to a static `dist/` folder.

## Consequences

- No server runtime for the frontend: cheaper hosting and one fewer thing to operate.
- No SEO for dynamic content. That is acceptable for a monitoring tool.
- If SSR is ever needed, TanStack Router routes move to TanStack Start without rewriting components.
